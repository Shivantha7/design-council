# Structural Productivity Potential (exploratory)

**Exploratory, post hoc relative to the pre-registered study.** These are estimates of the *expected productivity potential under stated assumptions*, built into the council designs. They are not measured operational outcomes. Method: `docs/PRODUCTIVITY_METHOD.md` (`a67c2af`). Classification decisions: `docs/PRODUCTIVITY_DECISIONS.md` (`4ab2958`). Both were committed before computation. Generated by `scripts/productivity_heldout.py`, whose docstring records the implementation choices C1 to C10, fixed before the first computation.

Seed 20261011 (bootstrap seed 20261012); 10,000 Monte Carlo draws; 10,000 bootstrap resamples; Python 3.12.13 `random` (Mersenne Twister). 33 council runs over 7 held-out workflows. The baseline is excluded (method section 1). PI = 1 − H / H_original, where H_original = 1. Primary and agentic-only use the same draws.
